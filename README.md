📚 eduSMS – School Management System

eduSMS is a complete web-based School Management System developed using PHP, MySQL, HTML, CSS, and JavaScript. This project is designed to automate and manage daily academic and administrative activities of a school in an efficient and user-friendly way.

The system provides separate dashboards for Admin, Teachers, and Students, ensuring secure role-based access and smooth management of records.

🚀 Features

🔐 Secure Login & Authentication (Admin / Teacher / Student)

👨‍🎓 Student Management (Profiles, Courses, Results)

👨‍🏫 Teacher Management & Timetable

📝 Attendance Management (Student & Teacher)

💰 Fees Management & Payments

📊 Exams, Grades & Mark Sheets

🪪 Certificate & ID Card Generation

📢 Notification System

📁 Reports Generation & Export

🗂 SQL Database Included for Easy Setup

🛠 Technologies Used

Backend: PHP

Database: MySQL

Frontend: HTML, CSS, JavaScript, Bootstrap

Server: XAMPP / Apache

🎯 Purpose of the Project

This project is developed for learning and practical implementation of web development concepts and can be used as a Final Year Project / Semester Project. It helps educational institutes digitize their operations and reduce manual workload.

📌 How to Run

Clone or download the repository

Place the project folder in htdocs

Import the database from /sql/edumanage.sql

Configure database in config.php

Run using http://localhost/eduSMS
